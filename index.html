WXCON

Irish Weather Threat Console.

WXCON transforms Met Éireann weather warnings into a military-style threat assessment console. Inspired by Cold War-era command systems, it presents Ireland's real-time weather situation through a retro CRT terminal interface — complete with phosphor glow, scanline effects, and monospaced readouts.

FEATURES

  • Real-time Met Éireann warnings mapped to threat levels: GREEN, YELLOW, ORANGE, RED
  • National threat board with pulsing alert indicator and current conditions
  • All 26 counties individually tracked with per-county warning breakdown
  • 48-hour hourly local forecast with precipitation highlighting
  • Warning communications log with full history
  • Automatic location detection within Ireland
  • Green phosphor and amber CRT colour themes
  • 15-minute automatic data refresh
  • No accounts, no ads, no tracking

DATA SOURCES

Warning data is sourced directly from Met Éireann's public warning feed. Forecast data is provided by Open-Meteo. WXCON does not collect, store, or transmit any personal data.
